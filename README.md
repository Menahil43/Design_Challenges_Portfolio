# Menahil Faiz — UI/UX Design Portfolio

A lightweight, responsive portfolio for Menahil Faiz, a UI/UX Designer and Software Engineering student at Jinnah University for Women. Menahil is pursuing a BS in Software Engineering and expects to graduate in 2027.

The portfolio presents six focused design challenges and an interest in creative problem-solving, user-centered interfaces, and thoughtful digital experiences.

## Design challenges

1. **GreenHands Sign-Up** — A welcoming, accessible registration experience.
2. **Credit Card Checkout** — A straightforward, trustworthy online payment journey.
3. **Enchanted E-commerce Storefront** — An engaging storefront with intuitive navigation.
4. **Calculator Interface Design** — Clear hierarchy and intuitive everyday controls.
5. **TaskNest App Icon** — A recognizable visual identity for a productivity app.
6. **User Profile Studio** — An organized and visually appealing profile interface.

Each challenge card opens its corresponding Figma design in a new tab.

## Run locally

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript; Google Fonts are loaded over the internet.
